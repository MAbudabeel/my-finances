          Backup

          Your data lives only in this browser. If you delete Safari's website data, change phones, or don't open the app for a long time, it can be lost. A backup file is encrypted with your password; save it to Files or iCloud Drive.

          Al Rajhi texts

          An iPhone Shortcut collects each Al Rajhi text as it arrives. Run the “Bank texts” shortcut, then tap Paste texts here. Setup steps are in the guide that came with the app.

          You can also copy a single text from Messages (press and hold → Copy) and tap Paste texts.

          Security

          It also locks when you leave the app for more than a minute.

          Quick unlock

          Your password still works and is still needed for backups. Changing the password or restoring a backup turns quick unlock off.
